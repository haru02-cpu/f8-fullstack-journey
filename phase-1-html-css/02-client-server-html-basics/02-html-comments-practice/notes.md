# Exercise: HTML Comments Practice
Covers lessons: 2.21, 2.22, 2.25

## What I practiced
- Opening syntax for a comment: `<!--`
- Closing syntax for a comment: `-->`
- Using comments to temporarily hide part of the page

## Challenges faced
- None major — the syntax is simple. Worth remembering that a commented-out element is only hidden from the *rendered* page; it's still fully visible in View Source / DevTools, so comments aren't a way to hide sensitive information.
- Comments also can't be nested (a `-->` inside a comment closes it early), which matters if commenting out a block that already contains other comments.
