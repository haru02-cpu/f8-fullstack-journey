# Chapter 01 - Introduction

## Overview

This chapter introduces the learning journey of HTML & CSS and provides guidance on how to study the course effectively.

---

## Learning Goals

- Build a solid foundation of HTML & CSS.
- Practice consistently through small projects.
- Focus on understanding instead of memorizing.
- Apply knowledge by completing exercises.

---

## Study Strategy

- Watch each lesson carefully.
- Complete every practice exercise.
- Commit code regularly using Git.
- Review previous chapters before moving forward.

---

## Personal Notes

- Practice is more important than watching videos.
- Keep project structure clean and organized.
- Write meaningful commit messages.
- Learn step by step without skipping fundamentals.
