Hướng dẫn xây dựng ứng dụng Todo List bằng HTML, CSS và JavaScript

Todo List là một trong những dự án cơ bản giúp người mới học lập trình web làm quen với HTML, CSS và JavaScript. Trong bài viết này, chúng ta sẽ xây dựng một ứng dụng Todo List với ba chức năng chính:

  • Thêm công việc mới.
  • Hiển thị danh sách công việc.
  • Xóa công việc.

Bước 1. Tạo cấu trúc HTML

Trước tiên, chúng ta tạo giao diện cơ bản gồm ô nhập nội dung, nút thêm và khu vực hiển thị danh sách công việc. 

        <!DOCTYPE html>
        <html lang="vi">
        <head>
            <meta charset="UTF-8">
            <title>Todo List</title>
            <link rel="stylesheet" href="style.css">
        </head>
        <body>
        
        <div class="container">
            <h1>Todo List</h1>
        
            <div class="input-group">
                <input type="text" id="todoInput" placeholder="Nhập công việc...">
                <button id="addBtn">Thêm</button>
            </div>
        
            <ul id="todoList"></ul>
        </div>
        
        <script src="script.js"></script>
        
        </body>
        </html>

Giải thích

Đoạn mã trên tạo giao diện ban đầu của ứng dụng.

  • <input> dùng để người dùng nhập công việc.
  • <button> dùng để thêm công việc.
  • <ul> sẽ chứa toàn bộ danh sách Todo.
  • File CSS và JavaScript được tách riêng để dễ quản lý và bảo trì.

Bước 2. Thiết kế giao diện bằng CSS

Sau khi có cấu trúc HTML, chúng ta tiến hành định dạng giao diện để ứng dụng đẹp và dễ sử dụng hơn. 

    body {
        font-family: Arial, sans-serif;
        background:#f5f5f5;
    }
    
    .container {
        width:400px;
        margin:50px auto;
        background:white;
        padding:20px;
        border-radius:8px;
    }
    
    .input-group {
        display:flex;
        gap:10px;
    }
    
    input {
        flex:1;
        padding:10px;
    }
    
    button {
        padding:10px 20px;
        cursor:pointer;
    }
    
    ul {
        list-style:none;
        padding:0;
        margin-top:20px;
    }
    
    li {
        display:flex;
        justify-content:space-between;
        padding:10px;
        margin-bottom:10px;
        background:#eeeeee;
    }

Giải thích

Phần CSS giúp giao diện trực quan hơn.

  • .container đặt toàn bộ ứng dụng vào giữa màn hình.
  • display:flex giúp ô nhập và nút nằm trên cùng một hàng.
  • Các phần tử <li> được hiển thị theo dạng từng dòng, dễ quan sát và thao tác.

Bước 3. Lấy các phần tử HTML bằng JavaScript

Trước khi viết chức năng, chúng ta cần lấy các phần tử HTML để JavaScript có thể thao tác. 

const input = document.getElementById("todoInput");
const addBtn = document.getElementById("addBtn");
const todoList = document.getElementById("todoList");

Giải thích

Ba biến trên lưu tham chiếu đến các phần tử trong HTML.

  • input đại diện cho ô nhập công việc.
  • addBtn đại diện cho nút Thêm.
  • todoList là danh sách sẽ chứa các công việc.

Bước 4. Viết hàm thêm công việc

Tiếp theo, chúng ta xây dựng chức năng thêm công việc mới vào danh sách. 

function addTodo(){

      if(input.value.trim()===""){
          alert("Vui lòng nhập công việc!");
          return;
      }
  
      const li=document.createElement("li");
  
      li.innerHTML=`
          <span>${input.value}</span>
          <button>Xóa</button>
      `;
  
      todoList.appendChild(li);
  
      input.value="";
  }
Giải thích

Hàm addTodo()thực hiện các công việc sau:

  • Kiểm tra người dùng đã nhập nội dung chưa.
  • Tạo một phần tử <li> mới.
  • Thêm nội dung công việc cùng nút Xóa.
  • Đưa phần tử mới vào danh sách.
  • Xóa nội dung trong ô nhập để chuẩn bị nhập công việc tiếp theo.

Bước 5. Gắn sự kiện cho nút Thêm

Sau khi có hàm thêm công việc, chúng ta cần gọi hàm này khi người dùng nhấn nút. 

addBtn.addEventListener("click", addTodo);
Giải thích

addEventListener() giúp lắng nghe sự kiện.

Khi người dùng nhấn nút Thêm, trình duyệt sẽ gọi hàm addTodo() và tạo một công việc mới trong danh sách.


Bước 6. Viết chức năng xóa công việc

Tiếp theo, chúng ta bổ sung khả năng xóa từng công việc.

todoList.addEventListener("click",function(e){

      if(e.target.tagName==="BUTTON"){
          e.target.parentElement.remove();
      }
  
  });
Giải thích

Thay vì gắn sự kiện cho từng nút Xóa, chúng ta sử dụng Event Delegation.

Khi người dùng nhấn vào nút Xóa:

  • Kiểm tra phần tử được nhấn có phải là <button> hay không.
  • Nếu đúng, lấy phần tử cha (<li>) và xóa khỏi danh sách.

Cách này giúp các công việc được thêm sau vẫn có thể xóa mà không cần gắn sự kiện mới.


Bước 7. Kiểm tra kết quả

Sau khi hoàn thành toàn bộ mã nguồn, hãy mở file index.html trên trình duyệt và thực hiện các bước sau:

  1. Nhập tên một công việc.
  2. Nhấn nút Thêm.
  3. Quan sát công việc xuất hiện trong danh sách.
  4. Nhấn nút Xóa để loại bỏ công việc vừa tạo.
Giải thích

Nếu cả ba chức năng đều hoạt động bình thường thì ứng dụng Todo List đã hoàn thành.

Bạn đã xây dựng được một ứng dụng CRUD đơn giản với hai thao tác cơ bản là Create (thêm) và Delete (xóa), đồng thời biết cách hiển thị dữ liệu trực tiếp trên giao diện bằng JavaScript.


Kết luận

Thông qua dự án Todo List, bạn đã thực hành được nhiều kiến thức quan trọng như:

  • Xây dựng cấu trúc giao diện bằng HTML.
  • Thiết kế giao diện với CSS.
  • Thao tác với DOM bằng JavaScript.
  • Xử lý sự kiện khi người dùng tương tác.
  • Tạo, hiển thị và xóa phần tử HTML bằng JavaScript.

Đây là nền tảng quan trọng trước khi học các chủ đề nâng cao hơn như Local Storage, Fetch API, React hoặc các framework JavaScript hiện đại.
