Xin chào!

Xin chào, mình là Haru. Hiện mình là một giáo viên tiếng Anh và đang học thêm về lập trình Web để phát triển kỹ năng cá nhân. Mình yêu thích việc học công nghệ mới và luôn cố gắng cải thiện bản thân mỗi ngày.


Giới thiệu ngắn

Mình sinh sống tại Thành phố Hồ Chí Minh. Chiều cao của mình khoảng 175 cm, thích đọc sách, học ngoại ngữ và viết các ứng dụng nhỏ bằng HTML, CSS và JavaScript.
